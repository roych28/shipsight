Vercel נתן וי ירוק, שלחתי ללקוח קישור, והוא ענה "הכפתור יוצא מהקופסה באייפון". פעם שלישית בחודש. אז בניתי לזה כלי, והוא חינמי.

הבעיה: פריסה ירוקה אומרת שהקבצים עלו. היא לא אומרת שהדף שהלקוח פותח נראה בסדר. כפתור חצי על הכרטיס וחצי מחוץ לו, טקסט חתוך ב-390 פיקסל, דף שנגלל לרוחב, תמונה שלא נטענה, שגיאת JS שהרגה את התפריט. כשבונים עם AI זה קורה הרבה, כי הקוד "נכון" והפריסה לא.

מה יצא: ShipSight. פלאגין ל-Claude Code ותוסף ל-VS Code שפותחים את האתר החי כמו מבקר, בכרום ובמנוע של ספארי, ברוחב מחשב וברוחב טלפון, גוללים אותו עד הסוף, ומחזירים רשימת ממצאים עם צילום מסך לכל אחד והאלמנט מסומן באדום. בתוך Claude Code זה `/shipsight <כתובת>`, ו-Claude לא אומר "פרוס" כשיש ממצא.

איך זה נבנה, מאחורי הקלעים:
- זה התחיל כסקיל פרטי שלי. אחרי שלקוח תפס אותי פעמיים על אותו סוג באג, כתבתי לעצמי כלל: אין פריסה בלי בדיקה חיה בכרום ובספארי. הפכתי את הסקיל למוצר כי כל מי שמוסר אתרים צריך את זה.
- Claude Code כתב את הקוד. אני הגדרתי מה בדיקה טובה צריכה לתפוס, הרצתי על האתרים של הלקוחות שלי, ואמרתי לו מה פספס ומה הוא המציא.
- איפה נתקענו: ממצאי שווא. קרוסלה עם שקופית שקופה נראית לכלי כמו תמונה שבורה, ובלוק "fade in on scroll" נראה כמו תוכן מוסתר. הפתרון היה לגלול כמו בן אדם (400 פיקסל, הפסקה, עוד 400) ולבדוק את המדיה רק בסוף, ולזהות קרוסלה לפי חפיפה בין תמונות ולא לפי שם המחלקה.
- עוד נפילה: בבדיקות האוטומטיות הדפדפן קיבל timeout על כל דף. הסיבה: השרת המקומי של הבדיקות והבודק רצו באותו תהליך, והקריאה הסינכרונית חסמה את השרת. שינוי של שורה אחת, שעה של חיפוש.
- בדיקות: דף שבור בכוונה (כפתורים צמודים, תמונה 404, גלילה לרוחב, שגיאת JS) והכלי חייב לקרוא לכל תקלה בשם הנכון. דף נקי בכוונה עם קרוסלה ו-reveal, והכלי חייב להחזיר "נקי". רץ בגיטהאב על לינוקס ומק בכל דחיפה, כולל התוסף בתוך VS Code אמיתי.

מה אני לוקח מזה לכל מי שבונה אתרים עם AI:
1. הדבר האחרון לפני שליחת קישור הוא לפתוח את האתר בטלפון. אם אין לכם כוח, שיעשה את זה כלי.
2. ספארי זה לא כרום. חצי מהבאגים שלקוחות מדווחים הם רק באייפון.
3. כשכלי בדיקה מחזיר ממצא, אל תסתירו אותו בפילטר. תבינו למה הוא חשב ככה, ותתקנו את הכלי.

הכל בקוד פתוח, MIT, רץ על המחשב שלכם בלי שרת. זה הכלי השני שלי אחרי Billable, ואני ממשיך להוציא כלי חדש כל שבוע. אשמח לשמוע איזה באג הלקוח תפס אצלכם אחרי פריסה ירוקה.
