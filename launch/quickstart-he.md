# ShipSight: איך משתמשים, בשתי דקות

ShipSight בודק אתר חי אחרי פריסה כמו שמבקר רואה אותו: בכרום ובמנוע של ספארי, ברוחב מחשב וברוחב טלפון. הוא מחזיר רשימת ממצאים עם צילום מסך לכל אחד, והאלמנט הבעייתי מסומן באדום. מה שהוא תופס: כפתורים צמודים או חורגים מהקופסה, טקסט חתוך, דף שנגלל לרוחב, תמונות שלא נטענו, שגיאות JavaScript ובקשות שנכשלו.

יש שתי דרכים להשתמש בו. שתיהן חינמיות, הכל רץ על המחשב שלכם.

## דרך 1: בתוך Claude Code (הכי נוח למי שבונה עם Claude)

התקנה פעם אחת. השורות שמתחילות בסלאש מוקלדות בשורת הצ'אט של סשן Claude Code פתוח, לא בטרמינל:

```
/plugin marketplace add roych28/shipsight
/plugin install shipsight@shipsight
```

מי שמעדיף טרמינל מתקין כך, בלי להיכנס לסשן:

```
claude plugin marketplace add roych28/shipsight
claude plugin install shipsight@shipsight
```

שימוש, בכל סשן, בשורת הצ'אט:

```
/shipsight https://your-site.com/
```

מה קורה: Claude מריץ את הבדיקה, קורא את הדוח ואת הצילומים, ומחזיר סיכום. בריצה הראשונה הוא מתקין לבד את Playwright ואת שני הדפדפנים (דקה או שתיים). אם יש ממצאים, Claude לא יגיד "פרוס" לפני שהראה אותם.

אפשרויות:

```
/shipsight https://your-site.com/ --crawl
/shipsight https://your-site.com/ --widths 1728,1440,390
/shipsight https://your-site.com/ https://your-site.com/pricing
```

השורה הראשונה עוברת גם על כל הקישורים הפנימיים (עד 10 עמודים). השנייה בוחרת רוחבים. השלישית בודקת כמה כתובות.

הטיפ החשוב: הסקיל שמגיע עם הפלאגין אומר ל-Claude להריץ את זה אחרי כל פריסה ולפני שהוא שולח לכם קישור. אפשר גם לכתוב ב-CLAUDE.md של הפרויקט שורה אחת: "After every deploy run /shipsight on the live URL before reporting done."

## דרך 2: בתוך VS Code, Cursor או Windsurf

התקנה: בחלונית התוספים לחפש ShipSight (המפרסם roychemo) וללחוץ Install. ב-VS Code זה מגיע מה-Marketplace, ב-Cursor וב-Windsurf מ-Open VSX.

שימוש:

1. לוחצים על העין בשורת הסטטוס למטה, או פותחים את הפלטה (Cmd+Shift+P) ובוחרים ShipSight: Check live site.
2. מקלידים את הכתובת, או בוחרים כתובת שכבר נבדקה.
3. הממצאים נפתחים בחלונית ליד הקוד, מקובצים לפי עמוד, עם צילום לכל ממצא. שורת הסטטוס מראה "3 findings" או "clean" עד הריצה הבאה.

בפעם הראשונה התוסף מבקש להתקין את הדפדפנים (כפתור Install, דקה או שתיים, פעם אחת). צריך node ו-npm מותקנים במחשב.

פקודות נוספות בפלטה: ShipSight: Check the last site again, ShipSight: Open a past report (כל הריצות הקודמות), ShipSight: Install the browsers.

הגדרות (Settings, לחפש shipsight): רוחבים (ברירת מחדל 1440 ו-390), האם לבדוק גם ב-WebKit, האם לעבור על כל הקישורים הפנימיים, וכמה עמודים לכל היותר.

## איך לקרוא את הממצאים

| תווית | פירוש |
|---|---|
| tight | שני כפתורים במרחק פחות מ-8 פיקסל |
| out | כפתור חורג מהכרטיס או מהסרגל שבו הוא יושב |
| offscreen | כפתור חורג מהמסך |
| edge | כפתור צמוד לקצה המסך בטלפון |
| small | כפתור נמוך מ-40 פיקסל בטלפון, קשה ללחוץ באצבע |
| overflow | טקסט חתוך בתוך כפתור |
| overlap | שני כפתורים אחד על השני |
| sideways | הדף נגלל לרוחב |
| broken-image | תמונה שלא נטענה, גם אם השרת ענה 200 |
| jserr | שגיאת JavaScript |
| resource | תמונה, סקריפט או גופן שענו 404 או 500 |
| http | העמוד עצמו לא נטען או ענה בשגיאה |

לכל ממצא יש צילום. פותחים אותו, רואים את הריבוע האדום, מתקנים, ומריצים שוב.

## מה הוא לא עושה

הוא מוצא שבירות פריסה ושגיאות, לא טעויות תוכן או עיצוב גרוע. WebKit הוא המנוע של ספארי ולא ספארי עצמו, ולכן הבדלים קטנים יכולים להישאר. אתר מאחורי התחברות צריך עמוד ציבורי או משתמש בדיקה. כל הדוחות נשמרים אצלכם בתיקייה ~/.shipsight/runs ולא נשלחים לשום מקום.
